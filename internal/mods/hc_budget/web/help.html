What HC Budget Setting is

HC Budget Setting maintains each process's machines, non-routine activities, and head count budgets in t_mqpd_hc_table — the same master table used by HC Scan Assign and the Dash HC pages.

  • Shared process picker: processes you choose are remembered across HC Budget Setting and HC Scan Assign during the browser session.
  • Stage first, save on Confirm: all edits, new entries, visibility changes, and display-order adjustments stay on screen until you review and press Confirm.

Permissions and roles

Process access comes from the same HeadCount group rules as HC Scan Assign. Within each permitted process, two roles apply:

CapabilityAuthorized userAdmin (Type = admin)
View active rowsYesYes
Edit Machine, Type, Category, Budget HCYesYes
Add Machine / ActivityNoYes
Show hidden / Hide / Restore rowsNoYes
Reorder Display SequenceNoYes

Editing budgets and machine details

  1. Choose a process on the picker screen (or press Change process in the top bar).
  2. Edit Machine / Activity, Type (Routine or Non-routine), Category (pick an existing suggestion or type a new free-text category), or Budget HC directly in the table.
  3. Budget HC accepts non-negative numbers (up to 8 integer and 12 decimal digits); leaving it blank saves as 0. The Total Budget HC counter at the top updates immediately.
  4. Read-only columns (Station, Cost Center, Last Updated) protect key identifiers on existing rows.
  5. Modified rows are highlighted. Press Discard at any time to revert all unsaved edits.

Admin actions: add, hide, and reorder

  • Add Machine / Activity: click + Add Machine / Activity. Enter a required Station Code (positive integer 1–32767, unique within the process across active and hidden rows) to generate the unique ID <process>_<station_code>. Cost Center and Process Code are pre-filled from the process's existing records and can be adjusted in the modal.
  • Hide and restore: click Hide on an active row to mark it hidden (it will no longer appear in HC Scan Assign or standard HC views). Toggle Show hidden in the top bar to inspect hidden rows and click Restore to bring any row back.
  • Display sequence: drag a row by its ⋮⋮ handle — or use the ↑ / ↓ buttons — to set the per-process order (1..N). Clear the filter box first if a search filter is active.

Note: Display sequence is maintained per process, because operators always pick machines within one process at a time.

Saving changes and cache refresh

Press Confirm to review a summary of your staged changes and commit everything in a single database transaction. After committing, the service appends an entry to MQPDHeadCount.log so Python Dash pages refresh their cached table automatically.

Header and Page Guide

Use the header controls to switch between light and dark theme, toggle English / 中文, open this guide, or launch the interactive page tour. See the dash_go user guide for general sign-in and interface help.

HC 预算设置是什么

HC 预算设置用于维护各工序在 t_mqpd_hc_table 中的机台、非例行活动和预算人力——这也是HC 扫码分派与 Dash HC 页面共同使用的主数据表。

  • 共用工序选择：你在当前浏览器会话中选择的工序会在HC 预算设置与HC 扫码分派之间共享。
  • 先暂存、后提交：所有编辑、新增条目、隐藏切换和排序调整都会先暂存在页面中，直到你核对无误后点击确认提交才写入数据库。

权限与角色

工序访问权限沿用与HC 扫码分派相同的 HeadCount 权限组规则。在有权限的工序内，区分两种角色：

功能普通授权用户管理员（Type = admin）
查看启用中的记录可以可以
编辑机台名称、类型、分类、预算人力可以可以
新增机台 / 活动不可可以
显示已隐藏 / 隐藏 / 恢复记录不可可以
拖动调整显示顺序不可可以

编辑预算与机台信息

  1. 在工序选择页点击要维护的工序（或在顶部栏点击切换工序）。
  2. 直接在表格中修改机台 / 活动、类型（Routine 或 Non-routine）、分类（可从已有分类下拉建议中选择，也可直接输入新文本）或预算人力。
  3. 预算人力接受非负数字（最多 8 位整数和 12 位小数）；留空将按 0 保存。顶部的预算总人力会随编辑实时更新。
  4. 已有记录的工位号、成本中心、最后更新为只读，以保护关键主键标识。
  5. 有改动的行会自动高亮；随时可点击撤销更改一键还原所有未保存内容。

管理员功能：新增、隐藏与排序

  • 新增机台 / 活动：点击+ 新增机台 / 活动。填写必填的工位号（1–32767 的正整数，在同一工序的启用与已隐藏记录中必须唯一），系统会按规则生成唯一 ID <process>_<station_code>。成本中心与工序代码会自动预填该工序的常用值，也可在弹窗内修改。
  • 隐藏与恢复：点击启用行的隐藏即可将其标记为隐藏（不再显示在 HC 扫码分派与常规 HC 页面中）。勾选顶部栏的显示已隐藏即可查看所有隐藏行，并可点击恢复重新启用。
  • 显示顺序：按住行首的 ⋮⋮ 手柄拖动，或点击 ↑ / ↓ 按钮，即可设置本工序内从 1..N 的显示顺序。若筛选框内有关键字，请先清空筛选框再排序。

提示：显示顺序按各工序独立维护，因为日常选择机台均在同一工序内进行。

确认提交与缓存刷新

点击确认提交后，页面会展示本次所有更改的汇总，确认后通过单次数据库事务原子写入。保存成功后会自动向 MQPDHeadCount.log 追加日志，通知 Python Dash 页面刷新缓存。

页眉与页面导览

可使用页眉按钮切换浅色/深色主题、切换 English / 中文、打开本手册或重新启动分步页面导览。更多通用登录与界面说明请查看 dash_go 使用手册。
