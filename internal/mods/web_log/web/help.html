What Web Log is

Web Log analyzes daily aggregated traffic stored in the PostgreSQL Log database (t_log_daily), showing both Action Count and Unique Visitors (IP) across applications, tools, and servers.

  • Public trend analytics: anyone on the network can open the trend chart and filter by date range, app, tools, and server without signing in.
  • Admin real-time stream: signed-in system administrators (T_USER_ALL.Type = admin) additionally see the live Redis web_log panel at the bottom of the page.

Date range, calendar views, and filters

  • Date range: choose any start and end date or use quick presets (7D, 30D, 90D, 12M). Daily queries allow up to 366 days; weekly and monthly views allow up to 5 years.
  • Standard calendar grouping: By Day uses calendar dates (YYYY-MM-DD), By Week uses ISO-8601 weeks (Monday–Sunday, YYYY-Www), and By Month uses calendar months (YYYY-MM).
  • Visitor count: every period on the line chart — and the headline KPI — counts distinct IP addresses within that period, deduplicated across apps, tools, and servers.
  • App & Tools filters: pick All Apps or any individual app (IE, QDB, MER, QAQC, API, DataBridge, Gitea, TimeVault, SSO, etc.), narrow to specific tools/categories, or check Exclude idle to remove background polling and static assets.
  • Server filter & By Server view: filter by one or more hosts (prod_eng, sgmescimai, sgmescimemg, ...). Historical rows with an empty or NULL host are normalized to prod_eng. Switch Stack By to By Server to compare server traffic side-by-side in stacked bars.

Reading and interacting with the chart

  • Dual axes: stacked bars map to Action Count (left axis) with total labels on top; the orange line maps to Unique Visitors (right axis).
  • Click to drill down: in All Apps view, clicking an app bar drills into that app's tools; in By Server view, clicking a server bar filters to that host. Clicking any row in the breakdown table below also applies that filter.
  • Top-15 chart folding: when more than 15 series match, the chart groups the long tail into Others (N) for clarity while the Breakdown table below lists every single item.
  • Toolbox: use the chart toolbar to zoom a sub-range, toggle bar/line style, restore the view, or save a PNG image.

Redis caching and refresh

Aggregated query results and filter options are cached in shared Redis so repeated views load immediately across all dash_go instances. Ranges touching yesterday or today refresh automatically within 10 minutes (matching hourly t_log_daily updates); purely historical ranges stay cached for 6 hours. Click Refresh in the top bar to re-query PostgreSQL directly.

Live Redis Web Log (Admin only)

When signed in as an active administrator (T_USER_ALL.Type = admin), the Live Redis Web Log panel appears below the breakdown table:

  • Reads the newest 200, 500, or 1,000 entries directly from the Redis web_log list (newest first).
  • Supports instant client-side filtering by keyword, server, and log level (error, warning, info, debug).
  • Optional Auto (5s) switch polls automatically and pauses while the browser tab is hidden.

Security: standard users and anonymous visitors cannot access this panel or its API endpoint (the server responds with HTTP 401/403).

Header and Page Guide

Use the header controls to switch light/dark theme (the chart adapts automatically), toggle English / 中文, open this guide, sign in, or launch the interactive page tour. See the dash_go user guide for general help.

Web 日志是什么

Web 日志用于分析 PostgreSQL Log 数据库（t_log_daily 表）中按日汇总的访问日志，同时展示各应用、工具及服务器的操作数（Action Count）与去重访客数（IP）。

  • 趋势分析公开访问：无需登录即可打开趋势图，按日期、应用、工具与服务器进行筛选分析。
  • 管理员实时日志流：已登录且在 T_USER_ALL 中 Type = admin 的系统管理员，会在页面底部额外看到 Redis 实时 web_log 面板。

日期范围、日历分组与筛选

  • 日期范围：自由选择起止日期，或点击快捷预设（7天、30天、90天、12个月）。按天视图最多支持 366 天，按周和按月最多支持 5 年。
  • 标准自然日历分组：按天采用自然日（YYYY-MM-DD），按周采用 ISO-8601 标准周（周一至周日，YYYY-Www），按月采用自然月（YYYY-MM）。
  • 访客数口径：趋势折线上的每个点以及顶部 KPI 卡片，均按对应时间周期内的去重 IP 数统计（跨应用、工具和服务器自动去重）。
  • 应用与工具筛选：支持选择全部应用或任意单个应用（IE、QDB、MER、QAQC、API、DataBridge、Gitea、TimeVault、SSO 等），并可进一步勾选特定工具/类别，或勾选排除 idle 过滤掉后台轮询与静态资源流量。
  • 服务器筛选与按服务器拆分：支持选择单台或多台服务器（prod_eng、sgmescimai、sgmescimemg 等）；历史记录中 host 为空或 NULL 的数据统一归入 prod_eng。将堆叠维度切换为按服务器即可直接在堆叠柱中对比各服务器流量。

趋势图阅读与交互

  • 双 Y 轴展示：堆叠柱对应左轴操作数并在顶部标注总计；橙色折线对应右轴周期去重访客数。
  • 点击下钻：在全部应用模式下点击某个应用的柱子，会直接下钻查看该应用下的各工具趋势；在按服务器模式下点击某台服务器的柱子，会筛选到该服务器。点击下方明细汇总表中的任意一行同样可联动筛选。
  • Top 15 折叠：当匹配分组超过 15 项时，图表保留操作数前 15 项并将长尾归入其他 (N) 保持画面清晰；下方的汇总表始终列出全部明细。
  • 图表工具栏：支持框选缩放、切换折线/柱状图、重置视图与一键导出 PNG 图片。

Redis 缓存与刷新

聚合查询结果与筛选项元数据会缓存在共享 Redis 中，多实例共享并显著加快访问速度。覆盖昨天或今天的查询缓存 10 分钟（匹配 t_log_daily 每小时汇总节奏），纯历史范围缓存 6 小时。点击顶部栏的刷新按钮可强制重新查询数据库并刷新缓存。

Redis 实时日志（仅管理员）

使用活跃的系统管理员账号（T_USER_ALL.Type = admin）登录后，汇总表下方会显示Redis 实时日志面板：

  • 直接读取 Redis web_log 列表最新 200 / 500 / 1,000 条记录（最新置顶）。
  • 支持按关键字、服务器与日志级别（error、warning、info、debug）即时过滤。
  • 可选开启自动刷新 (5秒)，切换至后台标签页时会自动暂停轮询。

安全说明：普通用户与未登录访客完全隐藏此面板，且后端接口会强制返回 HTTP 401/403。

页眉与页面导览

可通过页眉按钮切换浅色/深色主题（图表配色自动同步）、切换中英文、打开使用手册、登录账号或启动交互式页面导览。通用说明见 dash_go 使用手册。
